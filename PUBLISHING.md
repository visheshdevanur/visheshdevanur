# Publishing

1. Open the repository named `visheshdevanur` (the GitHub profile repository).
2. Replace its `README.md` with the supplied `README.md`.
3. Upload the entire `assets/` folder beside `README.md`; keep the filenames unchanged.
4. Commit the changes. GitHub will render the profile README and its relative SVG assets.

The project plates and hero/Edge AI artwork are custom abstract illustrations, not screenshots.
Project descriptions and tags intentionally avoid claiming unverified implementation details.
